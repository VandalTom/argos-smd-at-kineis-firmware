Simulator
Help: browser, adapter, wiring, recovery
  • Browser: Chrome or Edge on a desktop computer (Web Serial), at arribada.siliconvandals.com. Offline, open this file directly (file://) or serve it with python -m http.server and use http://localhost. Firefox and Safari don't support Web Serial.
  • Adapter: a 3.3 V USB-UART adapter (CP2102, CH340 or FT232). Prolific PL2303TA/HXA clone adapters don't work on Windows 11, because the driver blocks them.
  • Wiring: adapter TX → module P4 (PA3), adapter RX ← module P5 (PA2), GND ↔ GND. Never use 5 V signalling.
  • Baud: the app console runs at 115200 (older builds 9600). The bootloader may run at 9600 or 115200. Auto mode tries both.
  • Firmware file: flash the app-only build/argos-smd-at-kineis-firmware.bin, never the _full.bin (that one also contains the bootloader).
  • No DFU entry: if AT+BOOT= is refused, the unit runs an old build. Flash it once over SWD (make flash-full) or ST's ROM bootloader (BOOT0 + Tools/rom_uart_flash.py).
  • Failed update: the unit stays in the bootloader. Connect again and click Flash. While a valid app is still present, the bootloader returns to it by itself after 2 minutes without commands.
  • Sleep: between cycles the unit sleeps (STOP2) and the first received byte only wakes it. The tool sends a short wake preamble before the first command after 20 s of quiet, and retries once if that first command gets no reply. The 5 s state polling keeps the console awake; untick it to measure the real awake duty.
  • Not provisioned: a unit without ID, ADDR and SECKEY never starts its radio (state NO_CREDS, TX self-test "unprovisioned"). It starts by itself (+PROV=OK) once all three are written. Then reset and re-run the self-test to test TX.
  • Rescue mode: after 3 failed boots in a row the firmware runs console-only for 10 minutes (+RESCUE=, state RESCUE). Reflash it from the Flash panel.
  • Battery CRIT: below 2.10 V the unit drops GPS and the deployment burst, sends one TX per 2 h and skips the boot TX self-test (SKIP batt_crit). Charge the pack above 2.15 V and re-run.
  • Everything silent after a failed update: power-cycle the unit, then run python Tools/rom_uart_flash.py --port COMx --wait 120 --flash build/argos-smd-at-kineis-firmware_full.bin (COMx = your adapter's port). This tool writes the vector table last, so an interrupted update leaves the first flash word erased. The STM32WL then starts ST's ROM bootloader on the same pads, and no BOOT0 is needed.

Commission unit (guided)

Runs the production order: flash (when an image is loaded below and the unit doesn't already run it) → boot self-test (sensors) → write the credentials from the Credentials panel → wait for +PROV=OK → reset → boot self-test including TX → commissioning state → report. Each step stops the run if it fails.

    Kineis credentials
      FieldExpectedRead backResultNote

      The key is never shown in the console or the report. The unit reports only its CRC-32 (+SECKEYCRC=), which is compared with the CRC computed here. New credentials take effect after a reset, so this tool resets the unit and reads everything back again.

      Team credentials

      One vault for the whole team: the CLS credential sets (ID, ADDR, KEY, RCONF) and which unit has which. Sign in with your @siliconvandals.com Google account, then unlock it with the team passphrase. Keys are encrypted and decrypted in this page with that passphrase: the server only ever holds them encrypted, and logs every key fetch with your email.

      #IDADDRKeyRCONFStatusDevice SNAssignedNotesChanged

      Edits save to the server as soon as a cell is left (Enter = next row, Esc = undo the cell); if someone else changed the same set meanwhile, the table reloads and nothing is overwritten. Keys stay hidden (only their CRC-32 is listed): "Key" shows one for 30 s, and typing into a key cell replaces that key. "Use next free set" in the Kineis credentials panel takes the first free set here; a verified "Write, reset & verify" marks it in use with the unit's serial number, and "Erase credentials" frees it again (this works while the vault is locked too; changes made while signed out are kept in this browser and sent at the next sign-in). The vault locks after 15 minutes without use. A lost team passphrase cannot be recovered: keep it in the team's password manager.

      Offline vault (this browser)

      For when the team vault cannot be reached. Save a copy with "Save offline copy here" (or load a downloaded backup file), then unlock it here with the team passphrase. It stays encrypted in this browser (AES-256-GCM, key from PBKDF2-SHA256 with 600,000 iterations), is only decrypted in memory while unlocked, and locks after 15 minutes without use. Changes made here stay in this browser: upload them to the team vault when back online.

      #IDADDRKeyRCONFStatusDevice SNAssignedNotes

      Spreadsheet keys: Enter = next row, Shift+Enter = previous, Esc = undo the cell. Edits save automatically, encrypted. Import accepts the CLS CSV (comma, semicolon or tab) or .xlsx, with or without a header row; existing IDs are skipped, conflicting ones are listed. "Use" fills the Kineis credentials panel; after "Write, reset & verify" (or the guided run) succeeds, the set is marked in use with the unit's serial number, and "Erase credentials" frees it again.

      Commissioning
      —

      WAIT_FIX: waiting for the first GPS fix. BURST: one transmission per minute for 30 minutes. DONE: commissioned. This panel polls while it is open. Re-arm makes the unit behave as if freshly powered.
